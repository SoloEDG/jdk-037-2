## 接缝解题卡

页面顶部可切换「矿区对局」与「接缝解题卡」。

一张接缝卡由两次真实对局的稳定盘各框四列拼成：

- **捕获与框选**：稳定盘按关卡种子确定性重建，切片内容（晶石、特消、霜层）必须与捕获一致。
- **有限来珠**：作者为八列各自排定来珠顺序；片盘与合盘按全局列键读取**同一列的同一顺序**（颜色与 id 都相同）。
- **来源追踪**：每枚晶石记录 `origin`（片段 0/1）与 `born`（`board` 初盘 / `queue` 来珠）。下落、越界挪子只改位置，不改来源。
- **来珠耗尽**：某列队列用尽后重力保留空位，不会凭空补珠。
- **四步预算**：两片盘单独成盘时在四步内都达不到目标；合盘必须在同一预算内给出见证。
- **跨缝见证**：见证中的某一次消除必须同时跨接缝两侧，且两侧各至少有一枚初盘原珠（`born === 'board'`）参与该次清除。签名由步骤、波次、霜层与两枚样本派生。

发布前的校验（任一未通过或未完成都只能存草稿）：

1. 两帧来自不同的真实捕获，各为连续四列；
2. 八列内容与捕获逐格一致，片段归属正确；
3. 每列都排定有限来珠，且两盘同列同序；
4. 合盘与两片盘初盘均无三连；
5. 两片盘四步内清霜上限都低于目标（`proven`）；
6. 合盘在四步内找到达标且跨缝的见证；
7. 已存见证可重放复现同一签名。

搜索未完成（`unknown`，节点或时间上限截断）时只保存草稿，不写入发布见证。初盘已经三连时发布被拦截。

「按见证试玩」会从初盘重放卡上见证并高亮跨缝样本；也可以自己走子，跨缝发生后会与见证签名比对。分享按钮把种子、列内容与见证编码进地址栏，重新打开即据分享载荷重建卡片并复现跨缝贡献。
